# Post log: the plugin's own launch

The posts this plugin's author made with it, in the same format as
`state/post-log.md`, so `docs/results.md` can show real numbers rather
than only describe how they'd be collected. Summarized with
`python3 scripts/results.py --log-dir docs/results-data`. Numbers are
filled in with `publish_direct.py --metrics --log --log-file
docs/results-data/post-log.md` or pasted from Reddit, a day or two after
each post, and never estimated.
